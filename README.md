# Dr. Rick Wolthusen, MD, MPP — Flagship Website

Personal flagship website for Dr. Rick Peter Fritz Wolthusen — Staff Psychiatrist at
McLean Hospital, Instructor in Psychiatry at Harvard Medical School, and Co-Founder of
On The Move e.V.

## Stack

- Single static page (`index.html`) — no build step required
- Tailwind CSS (CDN), Font Awesome icons, Google Fonts (Inter + Playfair Display)
- YouTube embeds play in-app via a modal player

## Deploy

Static site — deployable anywhere (Vercel, Netlify, GitHub Pages). The site is served
from `index.html` at the repository root.
